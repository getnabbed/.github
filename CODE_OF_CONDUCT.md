# Code of conduct

Nabbed's projects adhere to the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, and assume good faith. Harassment,
discrimination and personal attacks are not tolerated.

Report unacceptable behaviour to the maintainers privately, the same way as a
security issue (see [SECURITY.md](SECURITY.md)). Every report is reviewed and
investigated promptly and fairly.
