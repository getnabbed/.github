## Nabbed

**Stop managing. Start watching.**

Nabbed keeps your film and series library up to date. Tell it what you want
to watch; it finds the best release for your quality settings, downloads it
on your own hardware and files it into your library, named and ready for
your media server.

### The agent

[**getnabbed/agent**](https://github.com/getnabbed/agent): the open-source
downloader that runs on your machine, NAS or Kubernetes cluster. It
downloads over usenet and BitTorrent and imports into your library, using
provider credentials that only it can read.

### Get started

1. **Sign up** at [app.nabbed.media](https://app.nabbed.media).
2. **Install the agent** with Docker, a binary or the Helm chart; see the
   [agent README](https://github.com/getnabbed/agent#readme).
3. **Pair it**: the agent shows a code on first start; approve it in the
   web app.
4. **Add your library folders** in the web app, and a usenet provider if
   you use one. Then request something to watch.
