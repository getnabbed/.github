# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately, never in a public issue,
using GitHub's private vulnerability reporting on the affected repository:
open its **Security** tab and choose **Report a vulnerability**. For the
agent, that is
[getnabbed/agent](https://github.com/getnabbed/agent/security/advisories/new).

Include a description of the issue, steps to reproduce, and the affected
version (for the agent, the output of `agent version`). We acknowledge
reports within a few days and work with you on a fix and a coordinated
disclosure.

## Supported versions

Only the latest release of each project receives security fixes.
